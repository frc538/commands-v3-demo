# Commands V3 Demo Project

This demo project follows examples close to what is demonstrated in [this playlist](https://www.youtube.com/playlist?list=PLQi1rSJWTcFI).

To run the code yourself in WPILib alpha7:
- Switch to the tag for the step you want to try (they're numbered)
- Run "WPILib: Simulate Robot Code"
- Make sure your keyboard or joystick or gamepad is placed correctly in the simulation
- Make sure to select the one Utility Op Mode
- Make sure to enable the op mode
- Press Button 0 on your input device, if needed (this is likely the Z key on a keyboard)

You can repeat the process for each tag.
